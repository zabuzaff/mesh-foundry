# Product brief

## Purpose and user

Mesh Foundry is a personal local art studio for a software developer with no Blender experience. Codex authors and revises work; the owner browses, compares, annotates, and accepts it. It must help produce real reusable geometry, materials, rigs and animation, beyond displaying models or generating concept images.

The creative loop is planning → Scene Loom → Mesh Foundry → Scene Loom → planning, repeated until the relevant designs align. Small technical game-import checks may happen before visual acceptance; production adoption is a separate decision.

## Agreed workflow

- Project → asset category → asset. An asset contains 2D candidates, 3D studies, model revisions and design decisions. Stages need not all exist at once.
- Project → animation workspace. Review reusable clips and simple compositions using referenced asset revisions.
- Prompt in Codex → agent produces a revision → studio updates → inspect and annotate → agent revises → owner accepts explicitly.
- First feedback tools: side-by-side comparison and clicking a model location to attach feedback. General text feedback remains available. Sliders are deferred until a concrete need justifies them.
- Copy-ready prompts identify exact work and instruct a new chat to read current decisions, source and feedback.
- Blender is approved as the underlying authoring tool. Routine owner use stays in Codex and the studio.

## First end-to-end outcome

One generic human base for fish.exe, one derived variation, a neutral pose, walk loop and fishing idle; editable source, rotatable review, comparison and annotations; consistent reference renders imported into Scene Loom; a bounded fish.exe compatibility check under separate authorization to touch that repository.

Working art direction: economical indie fantasy; understated goofy personality, slightly vacant expressions, modest awkward proportions. Avoid try-hard googly eyes, cute storybook mascots, detailed caricatures, gritty realism and elaborate anatomy. How to Fish is an inspiration, not an approved asset specification. Four mixed-gender fictional friends travelling in a jeep toward a fishing cove provide context, not first-version production scope.

Future assets include jeep, fish, rocks, trees and fishing gear. Support future games without promising every engine or device in v1.

## Exclusions

No custom modeling engine, full Blender replacement, embedded chat, automatic acceptance, cloud dependency, mandated AI generation service, team collaboration, marketplace, full scene editor, animation graph editor, automatic rig retargeting, or AAA production pipeline. Do not rebuild Scene Loom inside this tool.
